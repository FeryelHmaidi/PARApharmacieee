#  PARAPharmacieee

An e-commerce web application for a parapharmacy, designed to provide users with a simple and intuitive online shopping experience.

##  Live Demo

👉 [Visit the website](https://par-apharmacieee.vercel.app/)

##  About the Project

PARAPharmacieee is an e-commerce platform dedicated to parapharmacy products.

The application allows users to browse products, explore different categories, view product details, and manage their shopping experience through a modern and responsive interface.

## ✨ Features

-  Browse parapharmacy products
-  Product exploration
-  Product categories
-  Product details
-  Shopping cart
-  Responsive design
-  Modern and user-friendly interface
-  Online deployment with Vercel

##  Technologies

- HTML
- CSS
- JavaScript
